# ScanOn — דף נחיתה

דף הנחיתה הרשמי של ScanOn — כרטיסי NFC שמביאים לעסקים יותר ביקורות בגוגל.

## 🚀 איך מעלים עדכון (אם מעלים ידנית ולא דרך Claude)

1. גשו לריפו ב-GitHub.
2. **חשוב:** אל תגררו את *התיקייה* עצמה! פתחו את התיקייה במחשב, לחצו `Ctrl+A` לסימון **כל התוכן שבתוכה**, וגררו את זה לחלון ההעלאה של GitHub.
   (אם גוררים את התיקייה עצמה — כל הקבצים ייכנסו תיקייה אחת עמוק מדי, והאתר יישבר עם שגיאת 404.)
3. ודאו ש-`Settings → Pages` מוגדר על ברנץ' `main`, תיקיית `/ (root)`.
4. חכו כדקה, ואז בדקו את הכתובת החיה (עם `/` בסוף!).

## 🛠️ פתרון תקלות מהיר

- **האתר מציג 404** → כנראה שהעליתם את התיקייה במקום התוכן שלה. תקנו לפי סעיף 2 למעלה.
- **חסרים קבצים / עיצוב שבור** → יש קבצים מוסתרים (`.nojekyll`, `.gitattributes`, `.gitignore`) שלא רואים ב-File Explorer אלא אם מדליקים `View → Show → Hidden items`. בלי זה הם לא יעלו.
- **הכתובת לא עובדת** → ודאו שיש `/` בסוף הכתובת.
- **שינויים לא מופיעים** → GitHub Pages לוקח כ-30-60 שניות לבנות מחדש אחרי כל שינוי. רעננו בעוד דקה.

## 📁 מבנה הפרויקט

```
index.html          — העמוד הראשי
assets/styles.css   — עיצוב
assets/app.js       — אנימציות ואינטראקציה
assets/img/         — תמונות הכרטיס
assets/vendor/      — ספריות (GSAP, Lenis, Swiper) — מתארחות עצמאית
```
